
# Advanced Methods of Data Analysis

## Overview

This repository contains R programming assignments focused on statistical modeling, data analysis, and visualization.

Topics covered include:
- Generalized Linear Models (GLMs)
- Logistic and Poisson Regression
- Contingency Tables
- Fixed and Random Effects Models
- Mixed-Effects Models
- Hypothesis Testing and Model Selection
- Statistical Diagnostics

## Tools & Technologies

- **R** — Statistical computing and modeling
- **RStudio** — Development environment
- **R Markdown** — Reproducible reports and analyses
- **ggplot2** — Data visualization
- **faraway** — Statistical datasets
- **lme4** — Mixed-effects modeling
- **pbkrtest** — Kenward-Roger and bootstrap testing
- **RLRsim** — Random-effects significance testing
